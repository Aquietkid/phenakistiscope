# phenakistiscope
A simple phenakistiscope simulator with custom speed and interval.

# Tools Used

This project is built in Python3 and uses tkinter and PIL (pillow).

# How to Run

To run the project, you must have Python3 installed. You also need to install PIL:

`pip install pillow`

Then, run the python file, choose an image, and let the phenakistiscope action begin!
